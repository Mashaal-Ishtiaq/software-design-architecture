# Software Design and Architecture

A collection of Java coursework, lab tasks, software design resources, and projects completed as part of the Software Design and Architecture (SDA) course.

## Repository Structure

- `lab_tasks/` — numbered tasks and lab-task documents.
- `projects/` — Java projects, including GUI and population-growth examples.
- `resources/lab_manuals/` — lab manuals, UML diagrams, architecture examples, use cases, and supporting course materials.
- `practice/` — standalone Java practice programs.
- `archives/` — original ZIP archives supplied with the coursework.

## Languages and Tools

- **Language:** Java
- **Tools:** JDK, IntelliJ IDEA, or another Java-compatible IDE
- **Build tools:** Maven for projects that include a `pom.xml`

## Running Java Files

For a standalone Java file, compile and run it from the directory containing the file:

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the class name (without the `.java` extension). Some projects have their own structure or dependencies, so follow the project's configuration where applicable.

## Topics and Materials

The repository includes Java exercises, GUI development, MVC-related work, UML diagrams (such as class, activity, and use-case diagrams), client-server architecture, and lab manuals.

## Notes

- Existing source-code contents and project files have been preserved.
- Files have been grouped into folders to make the repository easier to browse.
- Some folders contain IDE-generated or compiled output files that were included in the original archive.
